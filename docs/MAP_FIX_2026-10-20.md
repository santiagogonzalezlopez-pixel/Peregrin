# Map zoom fix

The map used CARTO raster tiles without an API key. CARTO now adds an
"API key required" watermark to that usage, as described at
https://carto.com/basemaps/apikey.

## Change

- Use the standard OpenStreetMap HTTPS tile endpoint with linked attribution.
- Preserve the existing maximum zoom of 18, markers, filters and popups.
- Keep normal browser HTTP caching for tiles; no bulk or offline tile download.
- Identify the Android app in its WebView User-Agent, following
  https://operations.osmfoundation.org/policies/tiles/.
- Update the map provider in the privacy notice and the app shell cache to 50.
- Synchronize the root, `www` and Capacitor assets.
- Android versionCode 71 / versionName 1.0.70.

## Verification

- All nine existing app tests pass, including identical packaged web assets.
- A local browser fixture with no production account writes renders the map at
  zoom 18 with zero tile errors. Zooming out to 17 and back to 18 works.
- The Scherpenheuvel marker opens the correct sanctuary popup. No browser
  console errors or warnings were observed.
- The Auth/Firestore emulator privacy test passes.
- Android release compilation and signing pass. The first build encountered an
  AAPT2 link timeout; rerunning with `--max-workers=1 --offline` succeeded.
- The AAB's changed web assets match `www`, its app identification is present,
  and its merged manifest has version 71 and no Billing permission.
- AAB: `android/app/build/outputs/bundle/release/peregrin-1.0.70-map-fix.aab`.
- SHA-256: `F30064E34EF2F94E0EC6018726ED2E416E60420A199CD117B7B0945A71345956`.
